# 🍎 Catch Fruit - Jogo de Pegar Frutas

## Descrição

Catch Fruit é um jogo simples e divertido onde você controla uma cesta para pegar frutas que caem do céu, enquanto desvia de bombas! O objetivo é acumular o máximo de pontos possível sem perder todas as vidas.

## Como Jogar

### Controles
- **Mouse**: Mova o mouse horizontalmente para mover a cesta
- **Setas ← →**: Use as setas do teclado para mover a cesta
- **Tecla P**: Pausar/continuar o jogo

### Regras
- 🍎 **Fruta**: Vale +10 pontos
- 💣 **Bomba**: Perde 1 vida
- ❤️ Você começa com 3 vidas
- ⭐ A cada 100 pontos, a velocidade aumenta
- 🏆 Seu recorde é salvo automaticamente

### Objetivo
Sobreviva o máximo possível e conquiste o maior placar!
